---

## 📌 Project Overview 
CureCrafter is a **full-stack MERN web application** built using **React, Node.js, Express.js, and MongoDB**.  
It focuses on **REST API development**, **secure backend architecture**, and **responsive UI design**.

---

## 🚀 Core Features
- AI-based chatbot interaction
- Home remedies recommendation system
- RESTful APIs using Express.js
- Secure authentication (JWT)
- Responsive UI with Tailwind CSS

---

## 🧠 Technical Skills Demonstrated
- Full-Stack Web Development (MERN)
- REST API Design & Integration
- MongoDB Schema Design
- Authentication & Authorization
- Component-Based Frontend Architecture

---

## 💼 Business Value
- Improves access to basic health guidance
- Scalable architecture for future integrations
- Clean UI for better user engagement
